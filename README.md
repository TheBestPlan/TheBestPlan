## Projects

### Killing Floor

Tools

- [killingfloor-bot-client](https://github.com/TheBestPlan/killingfloor-bot-client) — Headless L2Walker-style client that speaks the native UE2 network protocol and passes Steam auth
- [killingfloor-map-viewer](https://github.com/TheBestPlan/killingfloor-map-viewer) — Desktop and browser 3D viewer for `.rom` maps, no KFEd needed
- [killingfloor-map-importer](https://github.com/TheBestPlan/killingfloor-map-importer) — Converts maps from other games (GoldSrc BSP) into Killing Floor levels
- [killingfloor-mutator-tools](https://github.com/TheBestPlan/killingfloor-mutator-tools) — Cross-platform UCC wrapper that compiles mutators without touching the game install
- [killingfloor-ucc-tools](https://gitlab.com/TheBestPlan/killingfloor-ucc-tools) — Node.js UCC wrapper bundled with the official SDK files for mutator compilation
- [killingfloor-maplist-generator](https://gitlab.com/TheBestPlan/killingfloor-maplist-generator) — Generates `KFMod.KFMaplist` entries for a server config
- [serverperks-tcp-server](https://gitlab.com/TheBestPlan/serverperks-tcp-server) — Java TCP server that connects the ServerPerks mutator to a MySQL database

Modding and archives

- [killingfloor-modding](https://gitlab.com/TheBestPlan/killingfloor-modding) — SDK tools, textures, models, skyboxes and tutorials for mapping
- [killingfloor-sdk-nonsteam](https://gitlab.com/TheBestPlan/killingfloor-sdk-nonsteam) — SDK files from the non-Steam version of the game
- [killingfloor-mutators](https://gitlab.com/TheBestPlan/killingfloor-mutators) — Large collection of mutators, skins, specimens and weapons
- Killing Floor maps from the internet — [Part 1](https://gitlab.com/TheBestPlan/killingfloor-maps-p1), [Part 2](https://gitlab.com/TheBestPlan/killingfloor-maps-p2), [Part 3](https://gitlab.com/TheBestPlan/killingfloor-maps-p3), [Part 4](https://gitlab.com/TheBestPlan/killingfloor-maps-p4), Part 5 ([1](https://gitlab.com/TheBestPlan/killingfloor-maps-p51), [2](https://gitlab.com/TheBestPlan/killingfloor-maps-p52), [3](https://gitlab.com/TheBestPlan/killingfloor-maps-p53))
- [killingfloor-projects](https://github.com/TheBestPlan/killingfloor-projects) — Archive of private Killing Floor server resources (2009-2015)
- [kfn-screenshots](https://gitlab.com/TheBestPlan/kfn-screenshots) — Screenshots from KillingFloor.Net servers (2014-2025)
