## Проекты

### Killing Floor

Инструменты

- [killingfloor-bot-client](https://github.com/TheBestPlan/killingfloor-bot-client) — Headless-клиент в стиле L2Walker: работает по родному сетевому протоколу UE2 и проходит Steam-авторизацию
- [killingfloor-map-viewer](https://github.com/TheBestPlan/killingfloor-map-viewer) — 3D-просмотрщик карт `.rom` для десктопа и браузера, без KFEd
- [killingfloor-map-importer](https://github.com/TheBestPlan/killingfloor-map-importer) — Конвертер карт из других игр (GoldSrc BSP) в уровни Killing Floor
- [killingfloor-mutator-tools](https://github.com/TheBestPlan/killingfloor-mutator-tools) — Кроссплатформенная обёртка над UCC: компиляция мутаторов без изменения установленной игры
- [killingfloor-ucc-tools](https://gitlab.com/TheBestPlan/killingfloor-ucc-tools) — Обёртка над UCC на Node.js вместе с официальными файлами SDK для компиляции мутаторов
- [killingfloor-maplist-generator](https://gitlab.com/TheBestPlan/killingfloor-maplist-generator) — Генератор записей `KFMod.KFMaplist` для конфига сервера
- [serverperks-tcp-server](https://gitlab.com/TheBestPlan/serverperks-tcp-server) — TCP-сервер на Java, связывающий мутатор ServerPerks с базой MySQL

Моддинг и архивы

- [killingfloor-modding](https://gitlab.com/TheBestPlan/killingfloor-modding) — Инструменты SDK, текстуры, модели, скайбоксы и уроки по созданию карт
- [killingfloor-sdk-nonsteam](https://gitlab.com/TheBestPlan/killingfloor-sdk-nonsteam) — Файлы SDK из non-Steam версии игры
- [killingfloor-mutators](https://gitlab.com/TheBestPlan/killingfloor-mutators) — Большая коллекция мутаторов, скинов, монстров и оружия
- Карты Killing Floor из интернета — [Часть 1](https://gitlab.com/TheBestPlan/killingfloor-maps-p1), [Часть 2](https://gitlab.com/TheBestPlan/killingfloor-maps-p2), [Часть 3](https://gitlab.com/TheBestPlan/killingfloor-maps-p3), [Часть 4](https://gitlab.com/TheBestPlan/killingfloor-maps-p4), Часть 5 ([1](https://gitlab.com/TheBestPlan/killingfloor-maps-p51), [2](https://gitlab.com/TheBestPlan/killingfloor-maps-p52), [3](https://gitlab.com/TheBestPlan/killingfloor-maps-p53))
- [killingfloor-projects](https://github.com/TheBestPlan/killingfloor-projects) — Архив ресурсов приватных серверов Killing Floor (2009-2015)
- [kfn-screenshots](https://gitlab.com/TheBestPlan/kfn-screenshots) — Скриншоты с серверов KillingFloor.Net (2014-2025)
